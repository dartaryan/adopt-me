# Adopt Me! - Pet Adoption Platform

Adopt Me! is a responsive React-based application that allows users to search for pets by location, animal type, and breed. The platform provides a smooth and user-friendly experience, featuring dark mode support, efficient data fetching, and detailed pet information.

## Features

- **Responsive Design**: Optimized for both desktop and mobile devices.
- **Dark Mode Toggle**: Easily switch between light and dark themes.
- **React Query**: Efficient data fetching and caching using `@tanstack/react-query`.
- **React Router**: Smooth navigation between search results and pet details.
- **Modern UI**: Custom CSS animations and styles for an enhanced user experience.

## Installation

1. **Clone the repository:**

   ```bash
   git clone https://github.com/yourusername/adopt-me.git
   ```

2. **Navigate to the project directory:**

   ```bash
   cd adopt-me
   ```

3. **Install dependencies:**

   ```bash
   npm install
   ```

4. **Start the development server:**

   ```bash
   npm start
   ```

   The application will be available at `http://localhost:3000`.

## Usage

- **Search Pets**: Use the search form to filter pets by location, animal type, and breed.
- **View Details**: Click on a pet to view detailed information and a larger image.
- **Dark Mode**: Toggle between light and dark themes using the sun/moon button in the header.

## Folder Structure

- `src/`
  - `components/`: Contains the main React components like `App`, `SearchParams`, and `Details`.
  - `fetch/`: Contains functions for fetching data from APIs.
  - `styles/`: Contains the CSS styles and animations.
